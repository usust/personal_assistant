# 用户 API 页面同步

## 补全后的执行提示词

以当前 `pa-backend/` 源码为准，更新实际 Web 目录 `frontend/` 的用户管理功能。核对接口路径、方法、返回数据、校验规则与权限；实现真实用户列表、新增、编辑、删除。编辑仅提交实际变化的白名单字段，密码留空表示不修改，不发送完整用户对象。保留账号规范化、昵称 Unicode 字符数和密码 UTF-8 字节校验；提供加载、失败重试、空状态、重复提交保护与删除确认。刷新页面后重新加载当前身份；当前账号角色变化后同步权限，删除自身后退出登录。保留工作区已有改动，补充接口契约测试并执行前端类型检查和生产构建。

## 接口映射

| 方法 | 路径（相对于 /api） | 页面行为 |
| --- | --- | --- |
| GET | /users | 加载全部用户，按后端 ID 顺序展示 |
| POST | /users/register | 新增普通用户，仅提交 account、nickname、password |
| PATCH | /users/:id | 管理员更新 account、nickname、password、role 中变化的字段 |
| DELETE | /users/:id | 管理员删除用户，兼容 204 无响应体 |
| GET | /users/me | 加载当前身份和角色，使用本项目集成路由 |

后端允许 admin 和 sys_admin 编辑、删除；创建接口固定创建 user。前端账号统一 trim 后转小写；昵称 trim 后须为 1～64 个 Unicode 字符；密码不 trim，须为 8～72 UTF-8 字节。后端不允许账号、昵称或密码为空，编辑表单空密码不纳入 PATCH。列表和身份加载失败时可刷新重试，写入失败保留输入或原列表。后端仍是权限校验的最终依据。
