# API 契约与 Apifox 同步

`aiconfig.openapi.json` 保存模型配置接口，`internal.openapi.json` 保存本次整理的任务、记账、健康、AI 和运行状态接口。路径和字段命名保持现有客户端契约；普通响应统一为 `code/message/data`。

本次同步目标：Apifox 项目 **8566884**，AI 分支 **ai/20261003-from-main-user-models**（8695469）。`apifox-internal-sync.json` 记录 57 个接口、54 个新增模型及资源 ID，111 个资源已回读核验。模型配置的独立同步记录见 `apifox-aiconfig-sync.json`。

接口按任务管理、记账管理、健康管理、AI 对话与识别、运行状态分组。输入模型列出可提交字段，输出模型隐藏归属 ID、密钥和内部持久化字段；PATCH 字段只经业务校验后通过 map 更新。同步快照仍包含归档记录、分期计划及版本，幂等命令仍返回对应操作原始业务结果。

更新本地契约时同时同步 AI 分支，再回读接口详情与 JSON Schema 核验；读取 CLI 已登录的本机凭证，无需在文档或命令中放置 Token。本次同步没有合并 main 分支。

## Apifox 接口功能目录

接口采用“模块 → 功能”两级目录，功能目录集中放置对应的查询、创建、修改和删除接口，不另按 HTTP 方法拆文件夹。

```text
任务管理
├── 任务与进度
├── 任务清单
└── 变更记录
记账管理
├── 账户与账单
├── 记账分类
├── 交易流水
├── 消费分期
├── 贷款计划
├── 预设与周期
├── 统计概览
├── 账本同步
└── 变更记录
模型配置
├── 配置管理
├── 提供商目录
└── 模型目录
健康管理
├── 健康数据
└── 分析报告
AI 对话与识别
├── 智能对话
└── 截图识别
```

认证模块沿用验证码、登录目录；用户模块沿用公开接口、当前用户、用户管理目录，用户列表归入用户管理。运行状态只有存活检查，直接保留在运行状态目录。

目录 ID、接口归属和回读核验见 `apifox-folder-organization.json`。移动接口保留原 ID、URL、请求字段、响应模型与认证协议。
