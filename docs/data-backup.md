# 数据备份文件

## 目标与边界

iOS 将当前账号的数据保存成一个带版本的 JSON 文件，用于后续恢复和数据结构迁移。备份保留原始记录 ID、记录之间的关联及业务时间，不以列表分页结果、图表或汇总值代替明细。

本次提供导出。导入和恢复需要按目标结构编写版本转换及关联 ID 映射，不能直接把旧数据文件当作当前版本的新增请求提交。

备份包含个人业务数据，不包含登录令牌、密码哈希、模型服务密钥。文件未经加密，应存放在可信位置；重新配置模型服务时需要重新填写密钥。

## 格式演进

- `format` 是固定的格式标识，用于区分其他 JSON 文件。
- `schemaVersion` 是备份协议版本，独立于 App 版本和数据库迁移版本。
- `exportedAt` 使用带时区的时间。
- 保留源账号和源服务信息，帮助恢复时确认数据归属；这些信息不能作为导入授权。
- 业务记录中的旧 ID 只用于关联，跨账号或跨实例导入时必须建立新旧 ID 映射。
- 新版本导入器必须先检查格式和版本，再执行对应的转换。未知的更高版本应明确拒绝，不能猜测字段含义或静默丢弃数据。

结构变化时新增逐版本转换，并保存脱敏样例作为回归用例。金额、时间、枚举和删除状态都应明确转换，特别是保留被历史流水引用的分类墓碑。

恢复流程应先完成文件校验和预览，再在明确的目标账号下执行事务写入。导入必须处理任务父子关系、财务账户与流水的引用、离线 ID 与服务端 ID 的映射，并区分替换与合并语义；不能重放历史流水后再重复套用备份余额。文件中的角色、源用户 ID 或服务地址均不授予权限。

## 服务端快照

`GET /api/backup/export` 要求登录，只导出认证用户本人的数据。响应遵循项目统一 JSON 信封；数据在同一数据库事务内读取，无列表分页截断。任一模块读取失败时整次导出失败，不生成缺少模块的成功文件。

业务范围包括任务清单、任务和操作历史；财务账户、分类（包括删除墓碑）、流水、预设、事件和余额快照；健康日汇总、健康报告、餐食和热量目标；本人创建的模型配置元数据（不含密钥，连接地址去除凭证、查询及片段）。财务同步回执属于运行协议，不作为业务恢复数据。

## iOS 使用与文件结构

入口为「我的 → 设置 → 数据导出」。登录后默认「全部数据」；也可选择「本机账本」，游客仅提供本机范围。生成成功后调用系统文件保存面板，可保存到“文件”中的本机、iCloud Drive 或其他已配置位置；只有系统确认保存成功后才显示“已导出”。全部数据请求失败时显示错误，不悄悄改成本机备份。服务端需同步更新以提供备份接口。

文件使用 `.json` 后缀，UTF-8，默认名 `PersonalAssistant-backup-<UTC时间>.json`。顶层公共字段为：

| 字段 | 含义 |
| --- | --- |
| `format` / `schemaVersion` | `personal-assistant-backup` / `1` |
| `scope` | `account` 表示本人云端与当前本机账本；`local` 表示仅当前本机账本 |
| `exportedAt` | 文件生成时间 |
| `source.serverURL` | 源服务 API 地址，帮助辨认数据来源，不用于自动切换服务 |
| `source.owner` | 云端快照的源账号，仅账号范围存在 |
| `serverExportedAt` | 云端一致性快照时间，仅账号范围存在 |
| `task` / `finance` / `health` / `modelConfigs` | 本人云端完整业务集合，仅账号范围存在 |
| `client` | iOS 版本、构建号、本机捕获时间、账本与白名单偏好 |

`client.financeLedger` 保存其自身的 `schemaVersion`、`active` 和仅含当前空间的 `spaces`。保留该空间所有原始业务字段、完整卡号、队列、临时 ID、别名、缓存及截图识别任务元数据，不读取其他账号或游客空间。截图图片、在途后台上传文件和系统授权不在备份范围；截图任务中的历史图片字段也会剔除。本机偏好仅包含外观、任务展示/范围/排序、分类布局和当前空间卡片顺序，不遍历整个 UserDefaults。截图外发同意等保存的业务元数据不应在恢复时自动生效，恢复端必须重新取得授权。

本机空间在发起云端请求**之前**序列化为独立字节，防止等待期间同步确认后队列移除造成遗漏。两侧分别记录 `client.capturedAt` 和 `serverExportedAt`，并非跨设备与服务端的单一事务。若本机命令已于云端快照前完成上传，两侧可能包含同一业务记录；将来的恢复器必须依据原始 ID、操作 ID 和别名处理重叠，不能直接拼接两组流水或重放已确认操作。生成期间账号、服务地址或空间发生改变则取消文件生成。

JSON 转换保留金额字符串与整数 ID，保留服务端扩展字段；不经过只含部分字段的界面 DTO。生成前检查协议版本、源账号以及全部必需集合，缺少模块或不兼容版本会拒绝导出。这些检查用于验证本应用生成的文件，不是面向不可信文件的完整导入校验器。

## 验证

`apps/iOS/Tests/DataBackupTests.swift` 可通过 `DATA_BACKUP_TEST_MAIN` 独立编译运行，无需模拟器或 Swift 宏插件；测试覆盖大整数与金额、分类墓碑、队列不可变快照、单空间范围、凭证/图片排除、版本与缺模块拒绝。`apps/iOS/Tests/run.sh` 包含此组测试及现有 iOS 回归。后端 `internal/backup` 测试覆盖全部集合、本人归属、历史数据完整性、只读事务选项及错误信封。
