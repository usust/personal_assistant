# iOS 健康管理：科幻 3D 重构提示词

## 意图理解

- 对象：iOS「健康管理」首页（`HealthDashboardView`：身体档案、每日能量参考、Apple 健康联接、健康指标、同步入口、清理入口）。
- 目标：把现有「暗色卡片 + 静态人物剪影」升级为科幻全息 3D 界面，用大量动画把身高／体重／年龄、能量参考与各项指标「展示」起来。
- 约束：只重构视觉与动效，不改变数据来源、授权流程、账号隔离与清理逻辑；读数仍只来自真实数据，缺失显示 `—`，动画不得暗示分数、比例或健康好坏；遵守「界面文案精简」规则，不新增解释性文字。

## 完整提示词

> 重构 iOS 健康管理首页，采用「科幻 · 全息 · 3D」视觉。
>
> **氛围**：深空黑底，叠加青／紫霓虹；背景为带透视的流动网格地板、漂浮粒子与顶部辉光，随时间缓慢运动。
>
> **主视觉**：身体档案中央是一座全息投影——悬浮人形加 3D 旋转光环、倾斜轨道及环绕光点，底部为向外扩散的投影底座与光锥，人形缓慢沿 Y 轴摆动并带青／紫色散重影，周期性扫描光束自上而下扫过。身高、体重、年龄三张玻璃面板分居左右，通过会「画出来」的连接线指向头部、躯干与腿部。
>
> **面板语言**：半透明玻璃、渐变霓虹描边、四角取景框；数值使用等宽圆体并从 0 滚动计数至实测值。
>
> **动效**：页面进入时面板沿 X 轴翻转入场并错峰；滚动时卡片依位置产生 3D 倾斜与淡出；分组切换使用共享胶囊滑动并让指标重新错峰入场；联接按钮呼吸发光，已联接状态点持续脉冲。
>
> **无障碍**：开启「减少动态效果」时所有循环、位移、计数动画停用并直接显示最终状态；开启「降低透明度」时面板改用不透明底色；文字对比度保持可读；装饰元素对辅助功能隐藏。
>
> **工程**：新增 `HealthSciFi.swift` 提供背景、全息人形、面板、计数数字、按钮样式等可复用组件；`HealthDashboardView` 只替换展示层，保留全部状态与读取逻辑；所有函数与重要代码块使用中文注释。

## 验收

- 首页所有数据、授权、清理行为与改版前一致。
- 减少动态效果下无持续动画；大字号下英雄区自动改为纵向布局。
- 暗色背景下状态栏与导航栏保持可读。

## 迭代：简化与内脏示意

- 视觉收敛为细线条玻璃面板，去除角标、色散、多层光环；背景网格与粒子减量。
- 主视觉改为体检式人体内脏示意（脑、心脏、肺、肝、胃、肾、腹部、体型），参数按部位关联：脑—年龄、睡眠；心脏—心率；肺—血氧、呼吸；肝—基础代谢；胃—膳食能量；肾—饮水；腹部—体重、BMI、体脂；体型—身高、性别、步行、活动水平。
- 仅有读数的部位参与轮播（5 秒）；心脏按真实心率搏动，肺按呼吸频率起伏；支持点选并重置计时。
- 减少动态效果或超大字号时不轮播，按部位列出全部报告卡。
