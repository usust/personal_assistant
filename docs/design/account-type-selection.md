# 账户类型选择 · iOS 与 Web

更新：2026-09-27。以用户提供的五张 iCost 截图为布局依据，并参考 [iCost 官网](https://www.icostapp.com/) 及 [App Store 页面](https://apps.apple.com/cn/app/id1484262528)。借鉴用途分组和图标列表的交互，不复制截图或品牌资产。

## 统一设计

- 首页标题「选择类型」，按资金、信用、充值、理财、应收、应付六类显示 66 个入口。
- 浅灰背景、圆角内容卡片、圆形图标、深色半粗名称、细分隔线与右箭头。已有支付宝、微信及银行品牌素材继续复用；其他类型使用项目自绘的金色通用图标。支持主题色变量与系统深色模式。
- 储蓄卡与信用卡进入二级银行选择。仅保留用户确认的 161 家银行，不恢复此前删除的九类目录入口；名称、拼音、首字母可搜索。
- 新增时先选择银行或账户，选择后才进入资料页；类型与机构合并为一个图标＋名称选项，账户名称必填、备注选填。取消、返回和重开选择页保留表单输入；编辑历史账户不自动规范化或改写机构原值。
- iOS 使用原生 NavigationStack/List。Web 使用 WorkspacePanel 第三栏，深入列表复用第三栏并可返回，不叠加第四栏或遮罩。Web 账户卡片同步按六类分组。

## 数据与同步

`shared/finance/account-kinds.json` 是类型目录唯一编辑源。`node scripts/sync-account-catalog.mjs` 生成两端类型资源与 Web 精简银行目录；加 `--check` 校验生成结果，Web build 默认执行检查。完整官方银行快照和审计记录仍位于 iOS 目录，详情见其 ACCOUNT_CATALOG.md。

六类是展示用途，仍映射后端已有七种 accountType。64 个具体类型保存后可以恢复，另外两个入口负责选择银行。信用欠款为负余额，还款使用转账；充值转入同样使用转账。当前只提供记账类型，不新增自动行情、分期、计息、汇率或授信功能，币种仍为人民币。PATCH 仅提交白名单内实际改变的字段，包含显式 false 和空字符串。

## 品牌素材修订

银行与具体品牌应优先显示从网络核对并保存的真实标志，不能将“有通用图标”当成“品牌图标已补齐”。当前 161 家银行均有来源记录，另新增 28 个产品／所属平台图标。缺失产品专属素材单独记录在 `shared/finance/brand-icons.json`，不伪造、不用相似应用冒充。品牌图标保持原色与比例，Web 不再强制圆形裁切；来源见两端 THIRD_PARTY_ICONS.md。

## 新增流程简化（2026-09-27）

参考 [Wallet 官方添加账户说明](https://support.budgetbakers.com/hc/en-us/articles/34453128217618-Adding-an-Account) 的先选择类型流程，以及 [YNAB 添加账户说明](https://support.ynab.com/en_us/how-to-add-an-account-ByoxswMJs) 的账户命名与余额设置；结合本产品采用以下设计：

- 先选择银行／账户，再填名称（如「招商银行工资卡 8888」）和可选备注，点击「创建账户」才发送 POST。
- 名称去除首尾空白后必须非空；名称最多 128 UTF-8 字节，备注最多 2000 字节。重复提交锁定，失败保留草稿。
- 不再单独收集卡号尾号；旧账户尾号保留，不从自由名称猜测或提取卡号。
- 初始余额和计入净资产在「更多设置」中配置；默认余额 0、计入净资产、人民币。资料页显示余额及统计设置摘要，空余额按 0 保存。初始余额不计为收入；欠款用负数。
- Web 继续复用第三栏；iOS 首次选择独立导航栈，完成任意深度选择后进入资料页。重新选择和设置返回均保留输入；取消不创建记录。
- 验证：Web 23 项测试与生产构建、iOS Debug 模拟器 SDK 编译通过。浏览器实际验证新增→储蓄卡→招商银行→名称／备注→更多设置→返回保留输入；未向真实服务写入账户，尚未真机验收。

## iOS 参考图布局调整（2026-09-27）

iOS 以用户最新截图为准，余额／币种／计入净资产从「更多设置」移到资料页第二张圆角卡片。第一张为机构、必填名称、选填备注。Web 保持上一版渐进设置流程。本次参考 [Apple Text fields](https://developer.apple.com/design/human-interface-guidelines/text-fields) 与 [Apple Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)，加入自适应输入、44pt 操作区域、可访问标签和提交进度。人民币固定显示，不增加无数据支持的记账可选开关。iOS Debug 编译通过，尚未完成设备视觉验收。
