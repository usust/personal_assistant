# 消费账单分期

入口：iOS、Web 交易流水中，已入账支出选择「转为分期」。分期子账单及主账单通过「查看分期」访问完整计划，Web 使用统一第三栏。

## 当前行为

- 继承原账单本金、账户、分类、交易对象和标签；保留原账单备注。
- 支持分期名称、2–480 期、首期入账日期、总利息、利息分期／首期入账、四舍五入／向下取整、尾差归首期／末期。
- 人民币金额以整数分计算，精度固定两位；每期金额必须大于零，本金、利息分别守恒。
- 首期日号逐月沿用，短月落到月末，后续月份恢复原日号。
- 试算不写账本。iOS 选项统一从底部弹出，保存不再二次确认。点击保存直接冲回原支出，原记录变为分期主账单，同时原子生成各期流水并立即入账已到期项，返回真实进度。
- 欠款按期计入。后台按 UTC+8 入账日期自动扣减账本余额并统计支出，启动立即检查、此后每分钟检查；创建计划和查询账本、账户或分期时也在用户锁事务中补记已到期项，不依赖后台是否已执行。补记保留原入账日期。未到期项仅在分期计划显示「待入账」，不进入交易流水和账户月份卡片（分页前过滤），普通 AI／周期草稿仍按原待确认流程处理。这不代表银行扣款或还款。信用卡还款仍走账户转账。
- 同规则保存重试、自动入账重试均幂等。跨用户访问隐藏记录；AI 不能转换分期。
- 已保存计划支持编辑完整分期规则；主账单不可通过普通流水接口删除，整计划通过分期管理操作处理。单期支持编辑分类、交易对象和备注；已入账单期支持部分或全额退款，累计退款不能超过该期金额。删除单期时撤销关联退款并退回已入账本息或尚未入账的预记本金，释放预留利息，其他期次不变；保留已删除状态，后台不再入账。

## 接口和迁移

- `POST /finance/transactions/:id/installment-preview`：规则试算。
- `POST /finance/transactions/:id/installment`：原子转换。
- `GET /finance/transactions/:id/installment`：完整计划与最新进度。
- `GET /finance/transactions/:id`：单期账单详情；沿用流水 PATCH、DELETE 和 refund 接口处理单期。
- 分期由后台自动入账；旧确认接口保留兼容，新客户端不再展示分期确认按钮。
- 流水列表在分期标志上方按「入账日期 · 消费分期 · 计划名称」显示，业务类型独立于分类和计划名称，标志显示「分期 21/24」；旧列表接口缺少字段时，iOS 读取关联计划补齐。
- 后端启动自动迁移流水表的分期快照、父账单 ID 和期次列；旧流水无需转换。上线需先升级后端。

## 未包含的参考图能力

自定义金额精度、独立账本、报销、不计收支和不计预算尚未实现。当前表单不展示不可执行的设置。


## 账户入口与计划管理

- iOS 账户流水页顶部使用账户摘要，显示余额／欠款、可用额度、账期提示和全部分期待入账本息；取消该页顶部搜索与类型、状态筛选，全局流水也取消顶部搜索和筛选，按自然月份折叠分组，月内按日期排列；全局月份汇总支出与收入，不计内部转账本金。
- 点击待入账金额进入该账户消费分期列表，展示名称、分类、账户、待入账金额、原本金、利息、专项恢复额、欠款计入方式及下次入账日期；长名称单行省略。
- 列表支持从已有支出新增分期，点击查看期次；左滑可完结、编辑或删除。编辑复用创建表单并预填全部设置，支持名称、分类、备注、期数、首期日期、起始期、额度恢复、欠款计入、利息及余数计算规则；本金和账户与创建时一样继承原支出。仅 PATCH 实际修改字段，试算不写账本，保存原子重算期次并按新旧净差调整余额。分类与备注只同步至原本尚未入账的期次，保留已入账期的单独资料修改。
- 修改首期日期会按新日期重新判定入账状态；未改日期时保留已入账期实际日期（含提前完结）。用户删除的单期保持删除；修改期数或生成范围而移除的期次可以恢复，复用流水 ID，保存重试不重复扣款。已有退款保留原关联，不允许移除其期次、把单期金额降至已退款额以下或把入账日期移至退款日期之后；失败整体回滚。
- 完结将剩余待入账期次按今天入账；已删除期次不会恢复。删除整计划撤销所有子账单和关联退款，回退已计入本金与利息，不恢复原消费流水。两项操作均确认后执行、原子提交且可幂等重试。
- `GET /finance/installments?accountId=...` 返回账户内完整计划摘要；`PATCH /finance/installments/:id` 使用已验证字段 map 更新；`POST /finance/installments/:id/finish` 完结；`DELETE /finance/installments/:id` 删除整计划。
- 当前只提供消费分期，账单分期另行实现。

## 信用账户本期账单

- 账户摘要与月份流水之间显示最近已结束账期的“剩余应还”，无账单日时提供设置入口；贷款账户不显示信用卡账单模块。
- `GET /finance/accounts/:id/statement` 按账户完整账本计算，不依赖流水分页。当前总欠款剔除未出账净消费、费用及未来分期已预记本金；还款、已出账退款和优惠优先抵减已出账欠款，未出账消费退款抵减对应未出账消费。开户或校准后的历史欠款保留在已出账部分。
- 金额为账本计算结果，不是银行同步的账单。账单日是否包含当天、短月月末和 UTC+8 自然日与月份归类保持一致。
- 点击“本期还款”预填转入信用账户与剩余应还，用户选择付款账户后保存普通转账；成功后刷新应还、账户与流水，不执行银行扣款。

- 月份卡片日期范围下显示“账单金额”标签，未结束账期为“未出账”；已结束账期由 `GET /finance/accounts/:id/statements?startDate=...&endDate=...` 批量重建截至期末的账本欠款。后续还款不改变历史账单金额，与顶部实时“剩余应还”区分；历史账目删除或校准会按当前有效账本重新计算，不是银行账单快照。
