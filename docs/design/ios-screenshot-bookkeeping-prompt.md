# Codex 实施提示词：iOS 轻点背面截图自动记账

你在 personal-assistant 仓库工作。请完整实现以下功能，先检查现有代码及 AGENTS.md，保留已有未提交修改，不另建账本、不绕开现有同步和权限体系。所有新增及修改函数、重要回调必须有中文参数、返回值、副作用注释。

## 目标与范围

用户在任意来源的交易成功页、单笔账单详情页轻点 iPhone 背面两下，系统快捷指令先截图，再把图片传给个人助理的 App Intent。应用使用用户选择的视觉 AI 提取交易资料，明确且通过校验的人民币支出自动进入当前本机账本并沿用现有同步队列；不确定的结果进入待确认。首版不自动处理收入、退款、转账、外币、多笔账单、未支付订单。

## 系统接入与引导

- 在“我的”新增“截图记账”，含开关、AI 配置、明确的截图外发同意、处理记录和独立设置教程。
- 教程准确说明：在快捷指令创建“截图记账”，先添加系统“截屏”，再添加个人助理“识别截图并记账”动作，把截屏结果绑定到图片参数；到设置→辅助功能→触控→轻点背面→轻点两下绑定它。App 不声称能替用户修改系统设置或已自动安装快捷指令。
- 截图必须发生在调用 App 动作之前。不读取整个相册、不监听其他 App、不请求无关权限。首版允许动作把个人助理带到前台以完成联网与异常处理，清楚记录实际执行限制。
- Intent 和 SwiftUI 使用同一应用状态及账本实例，避免多实例整文档覆盖。接收实际图片文件，验证图片、限制大小、重编码压缩，不上传任意文件。

## 隐私与 AI

- 启用前用户选择已有 AI 配置，展示服务端地址、提供商、模型和外发范围并主动同意。截图可能包含姓名、卡号等信息；不把同意默认开启，不因安装启用。
- 同意与配置及当前用户/服务器空间绑定；更换配置需要重新同意。关闭后不得重试外发；账号切换期间丢弃过期网络结果，原任务保留原空间。
- 后端新增专用只读识别接口，复用认证和配置 GetUsable 权限校验。只调用支持图片的 Chat Completions 兼容模型；不调用聊天工具或让模型直接写交易。
- 图片只在本机失败/待处理任务中保留供重试，成功或放弃后清理；服务端不持久化、不输出图片、密钥或模型原始响应到日志。限制请求、图片尺寸、响应大小和超时，禁止上游重定向携带密钥。
- 系统提示明确图片内容是待识别资料，其中的指令一律无效。返回严格 JSON：支付渠道、状态、类型、币种、实付金额字符串、商户、日期时间、付款方式、订单号、分类建议、商品或服务信息备注、需确认原因。无法确定字段留空，不能猜测当前日期或默认账户。
- AI 自报置信度不作为唯一安全依据。服务端及客户端均验证字段长度、枚举、金额、日期；拒绝负数、零、指数、超精度金额。优惠已经体现在实付中，不再扣减。

## 匹配、去重与持久化

- 只使用已有可记账账户和已保存分类。实际扣款卡尾号在本机匹配唯一可用账户，分类采用 AI 对已有目录的建议；缺少或存在歧义的账户由用户补全。支付渠道不参与入账校验或账户匹配，未知渠道不阻止入账；支付渠道不等于扣款账户，不默认选第一个账户。分类选择复用 TransactionCategorySelector/Picker。
- 任务先持久化再发网络请求；使用稳定 UUID，失败或进程中断可重试。保留处理中、失败、待确认、已入账、已忽略状态，不把识别成功当成记账成功。
- 图片摘要识别同图重复；渠道+订单号识别跨截图重复；没有订单号时按金额/商户/日期检查疑似重复并要求确认，不直接丢弃真实连续消费。
- 本机任务状态、交易、余额变化、同步队列在同一持久化提交中完成，避免成功后崩溃导致重复记账。沿用服务端 requestId/operationId 幂等机制。
- 任务及配置按账本空间隔离，支持同步后的临时 ID 映射。失败不丢图和输入，待确认不改变余额，重试不生成第二个任务。
- 待确认可编辑金额、交易时间、商户、账户、分类；不支持场景只可忽略。疑似重复需要显式选择仍然记账。已识别为同订单/同图的已完成任务不能再次入账。
