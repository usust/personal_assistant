# iOS 财务首页

- 首页默认选中 UTC+8 当前自然月，上方年月可点击打开底部月份网格，支持按年定位、前后月箭头及返回本月。
- 同一位置提供三张可左右滑动的卡片：默认为当月总支出、总收入、月结余；第二张为当前净资产、总资产、总负债；第三张为累计待报销、已报销、报销总额。资产与报销不伪装为历史月份快照，三页共用金额隐藏状态、动态字号与卡片布局。
- 顶部三个点菜单包含账户、分类管理和模板与周期，保留记一笔加号。删除独立交易流水入口，直接在首页显示所选月份的日流水卡片，复用详情、编辑、退款、删除和分页逻辑。
- 月度数据通过 `GET /finance/transactions-summary?startDate=YYYY-MM-DD&endDate=YYYY-MM-DD` 汇总完整范围，独立于流水分页。只统计已入账交易；退款抵减支出，手续费计入支出，内部转账本金不计收支。空月份返回零值。
- 统计读取前补记已到期分期，未来未入账分期仍只在分期管理中显示。切月会清空旧流水与旧统计；请求标识、会话和取消检查避免慢响应覆盖新月份。
- 上线需同步更新后端，以提供完整月份统计接口。
- 报销属于独立进度统计，支出可标记“需报销”并填写已报销金额，支持部分到账。累计金额通过 `/finance/overview` 读取完整账本，只统计已入账的有效支出，扣除关联退款，排除草稿、作废、删除、内部转账及分期主账单。报销设置不自动生成收入，也不修改余额或净资产。
