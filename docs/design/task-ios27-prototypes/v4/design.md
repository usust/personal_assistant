# 任务模块 v4：精修视觉与主任务图标

本版继承 [v3全部确认规则](../v3/design.md)，调整视觉并新增主任务文件夹图标设置；不改任务层级、进度求和与整树操作。交付为静态原型，不修改代码。

## 主任务图标

- 新建、编辑主任务表单增加“图标”选择字段。
- 选择器使用SF Symbols风格图标，支持搜索；常用区六列，展示任务、计划、目标、学习、工作和生活等图标。
- 点击图标先修改表单草稿，表单保存后持久化；取消不改原值。
- 列表、主任务详情、父主任务选择器使用同一已保存图标。
- 主任务图标与具体任务进度控件区分；具体任务没有下级。
- 建议跨端保存稳定图标键，维护键至SF Symbol的映射与旧数据回退。原后端主任务图标字段尚未实现，本稿不声称功能已落地。
- 当前原型背景色随清单主题表现；未增加主任务单独选色的额外功能。

## 视觉调整

- 清单列表与任务列表使用连续内容面、细分隔线和克制缩进，减少分块白色大卡片。
- 图标使用细线与低饱和底色，主任务可用火箭、叠层、目标等符号，不统一为蓝色文件夹。
- 统一字体层级、数值对齐和正文留白；用青绿色突出操作与进度。
- 编辑表单保留浮动标签；主任务编辑不增加大尺寸预览卡片。
- 导航与操作层表达液态玻璃；正文、字段与进度保持清晰普通背景。
- 图片只表现静态材质，不构成iOS27原生动态玻璃效果的验证。
