# 任务模块 v3：用户确认规则与原型

本版本依据对话中逐项确认的规则，替代 v1/v2。此前“结构／安排”菜单、单独调整归属流程、进度比例平均方案均不再采用。2026-10-05。

## 已确认模型

- 任务管理是原 App 的一个模块，全局只有一个“任务”入口。
- 先创建任务清单，在清单下创建主任务或任务。
- 主任务类似文件夹，可容纳主任务和具体任务，支持多层嵌套。
- 具体任务是执行叶子，不能容纳任何下级。
- 新建和编辑表单直接选择清单与父主任务；父主任务选“无”即放在清单根层。
- 父主任务选择只列出主任务，排除自身及自身后代；提交时仍需校验，防止循环。
- 允许跨清单移动。移动主任务时，全部后代同步移动；重新选择清单后父主任务必须来自目标清单。
- 主任务汇总全部下属具体任务的完成量之和／总量之和，不重复计算中间主任务。5/10页＋1/1次＝6/11，约54.5%；即使单位不同，仍按用户确认的数值求和，汇总只展示数值和百分比，不虚构共同单位。
- 没有下级的主任务显示“暂无任务”。有下级但没有具体执行叶子的主任务也建议显示“暂无任务”，避免空分母。
- 归档主任务同时归档全部下级；恢复主任务同时恢复全部下级，不重置进度。
- 删除主任务同时删除全部下级；只提供整树删除，确认界面显示影响数量，不提供保留下级选项。
- 具体任务都有完成量、总量、步长、单位；普通一次性任务使用0/1到1/1，总量1、步长1、单位次。
- 不创建“结构／安排”菜单，不创建任务模块独立Tab，不让用户通过单独的移动功能才能编辑归属。

## 流程与页面

任务入口 → 清单 → 主任务／任务。
任务页使用清单列表，点击进入清单内容；无清单时显示“暂无清单”与新建入口。
清单内容可展开主任务，点击主任务进入下级列表；新增按钮进入新建表单，类型选择“主任务／任务”。
新建主任务：名称、备注、清单、父主任务；主任务不显示可编辑进度字段。
新建任务：名称、备注、清单、父主任务、优先级、开始／截止、完成量／总量／步长／单位。
编辑时类型作为既有身份展示，不默认支持类型转换，因为用户只确认了归属变更；避免叶子与容器转换产生额外规则。
编辑归属：编辑表单 → 选清单 → 选父主任务或无 → 返回原表单 → 保存。单次保存提交清单与父级变更；不是单独调整归属页面。
父主任务选择器可以搜索、展开和显示路径，但不能选择具体任务。选择后保留其他输入，不立即持久化。
跨清单修改有后代的主任务时，在保存前仅显示必要提示“将同时移动N个下级”，提交应原子更新整个子树，失败保留原树与草稿。
任务详情：量化进度＋／－，按步长立即提交，0时禁用－，满量禁用＋；不足一步时截至总量；保存中防止重复写。
主任务详情：显示汇总进度、下级、备注；无下级“暂无任务”，不展示直接加减进度。
更多菜单提供编辑、归档／恢复、删除；删除确认显示子树影响范围。新建、编辑、保存和返回遵循原生导航。

## 界面约束

原 App 全局导航保持既有今日、任务、财务、健康、More显示；只在模块根页显示，推入页面隐藏。
页面标题居中小标题，不在内容重复页面名。主任务业务名称可出现在详情内容。
清单名称与备注在图标右侧紧邻并左对齐；新建清单居中实时预览，编辑清单无顶部预览。
新建清单颜色17常用色＋系统颜色盘，共18格，固定六列三行，颜色盘最后一格；图标用SF Symbols与跨端共用键。
任务表单字段有值／聚焦时标签在左上；无值在字段内；减少动态效果时弱化移动动画。
无常驻教学文案，只显示必要校验、结果或会影响决策的子树操作提示。
Liquid Glass使用系统导航栏、工具栏、TabView及主要操作的原生材质；内容列表／表单／进度保持系统背景，避免多层玻璃。
静态图片只展示材质与布局方向，不能证明实时折射、系统透明度、滚动形变已完全符合iOS27；实现需目标SDK公开API及系统运行验收。

## 与现实现差距

本轮未改代码。主任务、任务、清单、进度与父级数据模型已有；iOS编辑归属、带后代跨清单原子移动、级联归档／恢复、空主任务显示需按最终规则实现。
PATCH继续使用白名单校验map，只提交变化字段，保留0、false、空串、parentId:null。子树变更须服务端事务、用户隔离与循环校验。
