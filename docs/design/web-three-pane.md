# Web 三栏工作区设计规范

用户于 2026-09-26 确认：参考三竖层示意，所有弹窗、查看及扩展信息采用三栏逐层展开设计。采用参考图的空间关系，沿用项目现有配色。

桌面：`导航 / 对象列表 | 当前工作区 | 详情 / 扩展操作`。

- 第一栏负责导航；第二栏承载当前页面、列表和主要操作；第三栏按需展开，不使用遮罩，不遮盖前两栏。
- 统一入口为 `apps/web/src/components/WorkspacePanel.vue`，使用 `v-model`、`title` 和可选的 `footer` 插槽。由 `AdminLayout` 提供唯一挂载区域。
- 右栏内继续打开表单或详情时，旧层保留状态，新层替换显示；返回只关闭当前层。关闭最外层后，中栏收回空间。
- 新增、编辑、查看、任务备注、日程、财务模拟及危险操作确认都遵守此规范。确认使用 `confirmInPanel`，取消必须阻止后续业务写操作。
- 顶部标题与返回／关闭按钮固定，正文独立滚动，底部操作固定。保留可访问名称、键盘焦点和 Esc 返回；提交锁定通过 `show-close` 和 `close-on-press-escape` 控制。
- 宽度不超过 900px 时显示导航及当前信息层，不超过 520px 时扩展层独占工作区，通过返回恢复上一层。页面状态保留在挂载组件中。
- 表单宽度随第三栏变化，长内容滚动；不得保留原弹窗固定宽度。控件级下拉、日历选择器及反馈提示允许保持原位交互。

验收应覆盖：任务创建与备注、财务流水到自定义分类的嵌套返回、删除确认取消、日历选日、切换页面清理、保存期间禁止关闭，以及桌面和窄屏布局。

## 统一视觉规范（2026-09-27）

参考用户提供的分组账户表单，所有工作区采用浅灰背景、白色圆角卡片、细分隔线，保留靛蓝品牌主色；导航使用浅色底和明确选中态。公共令牌与组件外观位于 `apps/web/src/styles/workspace-theme.css`，由入口在基础布局后加载。

- 标题使用系统无衬线字体，金额使用等宽数字；财务辅助信息最小 12px，表格正文 13px，表单标签 14px。
- 第三栏使用固定标题和底部操作区，正文独立滚动。账户编辑按资料、余额与统计分组，短字段按标签／值横向排列，保留完整标签与焦点提示。
- 窄屏继续按层切换，输入字号提升为 16px，操作区考虑底部安全区；不要复制参考图的手机外壳、状态栏或留白比例。
- 参考资料：[Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)、[W3C 表单标签](https://www.w3.org/WAI/tutorials/forms/labels/)。参考图的低对比度占位文字不作为正文颜色标准。
