# iOS 本机财务与一键同步

## 用户行为

- 首次启动直接进入财务，不要求登录；财务与「我的」可在游客模式使用。
- 普通账户、分类、收支、转账（含手续费和返现）、退款、流水资料修改、删除及普通模板保存到本机。财务列表、筛选、月度汇总和信用账期读取本机完整账本。
- 「我的 → 同步」：未登录先认证，认证成功后自动绑定当前游客账本并同步；已登录直接执行。不展示账户匹配、合并确认或冲突选择。
- 首次同步保留双方账户；同名账户不自动合并，余额不相加。分类采用服务端已有的用户/名称/收支类型唯一目录映射。
- 后续保存约 2 秒后尝试同步，回到前台、恢复网络会触发同步，前台每 30 秒检查。iOS 后台挂起后不承诺定时运行，下次可执行时继续持久队列。
- 退出切换到独立游客账本；账号数据及未上传操作仍保存在原账号空间，重新登录恢复。令牌过期不删除本机账本。
- Web 页面和既有 API 调用保持原样。

## 持久化与同步协议

`FinanceLocalStore` 在 Application Support/Finance/ledger.sqlite 保存用户空间、记录集合、ID 映射、操作队列及最近同步时间。使用 SQLite 单行 JSON 文档作为首版存储格式，单条事务共同提交账本与队列，磁盘成功后才替换内存。不是 UserDefaults 或易失的 URL 缓存。文件使用 iOS 设备数据保护；凭证仍只放钥匙串。

`APIClient` 将财务请求交给本机存储，其他模块保持既有网络路径。复杂业务由统一入口转到服务端，不能用未上传的临时 ID 发起计算。

- `POST /api/finance/sync/commands`：稳定 UUID `operationId`、白名单 `operation`、目标 `id`、`body`。
- `GET /api/finance/sync/snapshot`：认证用户在同一用户锁事务下的账户（含归档）、分类、流水（含删除状态）、模板、分期摘要和计划。
- 新表 `finance_sync_receipts` 按用户和操作 ID 保存正文指纹与原始结果。业务操作和回执在同一事务提交。同标识同内容返回原结果，异内容返回 409，失败没有回执。所有业务仍复用原 Service 的权限、精度和 map PATCH 校验。
- 本机创建实体使用独立高位临时 ID，命令使用 UUID。收到回执时原子保存服务器 ID 对应关系、修正本机外键、移除该操作。后续命令在发送前按实体类型映射引用；旧界面路径仍可解析。
- 首版上传操作增量、下载完整一致性快照，不使用分页 GET 拼快照或时间戳猜测增量。上传队列清空后才下载，下载等待期间产生的新本机操作在新快照上重放。没有变化的快照不会刷新流水页面的观察版本。
- 登录合并是一次持久化空间迁移；游客队列只归属一次，旧账号数据不会转移给新账号。每个网络响应应用前核对空间、服务器及令牌，过期响应丢弃。

## 边界

- 周期计划生成、贷款计算与调整、消费分期转换与调整、关联返现子项操作仍需登录联网，正式期次由服务器产生。已同步的计划可以离线查看；离线期间展示最后同步的自动入账状态，不伪造后台已经运行。
- 同一记录的普通资料按服务端实际接受顺序更新；不按设备时钟覆盖整份账本。金额变动复用业务操作及幂等回执。
- 服务器拒绝的操作保留队列和本地输入，显示同步错误，不谎报同步完成，也不自动删除或擅自修正金额。该队列按依赖顺序重试；永久业务错误不会自动变成成功。
- 当前本地查询在内存集合上筛选，下载全量快照；大量历史数据需要后续拆分 SQLite 实体表、索引及服务端增量变更日志。首版不宣称已有增量下载。
- 游客没有云端副本，卸载或清除应用数据会失去未同步账本；本次没有新增导出、备份或跨设备游客恢复功能。
- 本次游客离线范围是财务；任务、健康服务器同步和 AI 仍沿用认证服务。

## 发布与验证

先发布本仓库 `pa-backend`，启动时迁移 `finance_sync_receipts` 并提供两个新端点，再安装 iOS。旧后端缺少端点时本机功能仍可使用，同步提示失败并保留队列。没有更改或部署 Web，也没有自动部署服务器。

Swift 专项测试覆盖：本地精确金额、优惠/手续费/返现、退款和冲销、PATCH 零值、强退恢复、失败事务、账号和服务器隔离、真实 URLSession 包装下提交后断线及跨重启重试、ID 映射、同名账户保留、下载期间新记账重放、无变化刷新、损坏文件保留。Go 测试覆盖同步回执、余额不重复修改、同键异内容、跨用户隔离、回滚和分类映射；SQLite 测试不替代部署环境的 MySQL 行锁并发验收。

专用空白模拟器 UI 回归：`LoanSwipeTests/testGuestFinanceAndSyncEntry`，验证不登录进入财务、设置中的同步进入认证、取消返回，不对真实账本操作。
