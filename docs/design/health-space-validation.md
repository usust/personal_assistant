## Xcode / iPhone 验收

1. 打开 `apps/iOS/PersonalAssistant.xcodeproj`，以实际签名账号构建运行；App ID 保留 HealthKit capability。
2. 我的 → 健康管理，分别检查全授权、部分授权、无记录与撤销权限。无数据为横杠，真实零值仍是零；刷新不上传手机数据。
3. 打开身体资料，检查身高/体重/年龄来源、活动水平和估算依据；缺失信息可补录。采用参考目标后在饮食记录核对数值。孕哺期/特殊指导与成人范围之外不生成通用目标。
4. 拍照或选图，完成授权、分析核对、保存。回到卡片应显示压缩照片；重新进入仍显示，重试网络保存不产生重复餐食。模拟缩略图写入失败后应允许仅重试本机保存。
5. 切换日期，检查空记录、缺失目标、接近目标和超过 100% 的实际比例。检查小伙伴初次填充/轻跳动画、减少动态效果静态状态和 VoiceOver 数值。
6. 在浅色、深色、最大动态字体、iPad 宽屏下检查卡片/表单/指标；降低透明度后按钮保持可读。
7. 删除单餐、删除云端健康数据、清理本机资料分别核对照片清理及作用域。换账号或服务器不得显示前一账户的资料或照片；清理本机操作不改变 Apple 健康或云端数据。

餐食缩略图和手动资料属于本机数据，排除备份；服务器接口及 Web 不存储照片。真实照片压缩大小、文件保护、HealthKit 授权与动画视觉仍以本轮真机验收为准。
