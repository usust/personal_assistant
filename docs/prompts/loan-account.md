# Codex 提示词：贷款账户跨端完善

请改造个人助理的贷款账户，参考用户提供的贷款表单，并以仓库实际 API 为准实现 iOS、Web、后端闭环。

1. 贷款独立于信用卡：保留名称、备注、币种、净资产开关和记账可选；隐藏信用额度、账单日及出账日归属。加入贷款本金、贷款机构、合同年利率（百分数，允许零）、等额本息／等额本金／先息后本、1–480 个按月期数、0–总期数的已还期数、首次还款日、可清除的关联收款账户。
2. 由同一后端计算还款试算，展示下一期日期、本金、利息、应还金额、计划剩余本金与总利息。每个利率阶段的月利率为该阶段年利率 / 12；精确金额以分存储，零利率单独处理，最后一期收敛本金尾差。首次还款日是每月锚点，短月取月末，之后恢复原日号。计划本金结清后无下一期；分期调息遵循第三阶段的历史保护规则。
3. 创建贷款默认以计划剩余本金形成负债余额，不把贷款本金算收入；关联收款账户只记录关联，不自动增加另一账户余额。编辑计划不自动改历史账本；实际剩余本金可通过显式欠款校准调整，并保留快照。还款仍走现有流水，本金转账、利息支出，不因日历到期自动扣账。
4. 每个字段有可见中文标签，页面不添加冗余教学文字。试算与真实账本区分；手动分期调息使用用户填写的年利率，不虚构自动 LPR 更新、罚息或银行账单同步。
5. PATCH 只提交变化字段；后端白名单验证后通过 map 更新。零值、false 和清空关联应生效。验证关联账户所有权与有效状态；跨字段校验必须基于合并后的完整数据，失败整体回滚；旧贷款可以无计划继续读取和编辑。
6. Web 使用 WorkspacePanel 第三栏；同步已有信用字段及提醒配置，不能声称浏览器关闭后仍会推送。iOS 本机提醒按贷款剩余期数排程，已还完不提醒。
7. 补充本金守恒、利息精度、零利率、短月／闰年、结清、PATCH 零值、权限、旧数据及两端编译验证。

## 第二阶段：iOS 贷款详情与完整计划

从资产列表点击贷款进入账户详情，编辑入口移到“更多”。详情顶部显示下一期应还、期次、还款日、实际剩余本金、原始本金和已还期数；真实流水按自然月分组，可折叠并加载更早月份。流入／流出按本账户视角计算，仅包含已入账记录；转账展示来源与去向，不能把本金流入称为收入。不推算无法追溯的历史欠款或交易时分。

新增完整贷款计划页，展示按已还期数划分的本金、利息、本息六项汇总与本金进度，列出全部期次的日期、应还、本金、利息及计划状态，支持全部／已还／待还筛选。金额沿用服务端精确计划；标明“按已还期数计算”，不能声称由真实流水逐笔核销。编辑后返回自动更新计划。

更多菜单提供修改、贷款计划、停用／启用记账选择和删除账户。复用已有 API；不把“停用记账选择”伪装成独立隐藏或归档功能，不添加无实现的按钮。删除先查询影响并确认，存在待确认流水时阻止。记账入口预选当前贷款为转入账户，只记录本金转账，不自动把本息总额作为本金，不自动增加已还期数。

覆盖旧贷款无计划、已结清、网络失败重试、分页月汇总完整性、账户删除、编辑回显、跨会话请求隔离、长名称与动态字体。保留新增和原有非贷款账户的编辑行为。

## 第三阶段：分期生效的利率与金额调整

用户所说的“汇率”按贷款年利率理解。iOS 在有期初本金的期次卡片上向左滑显示「金额」「利率」两个按钮，按所滑期次打开独立表单；不展示顶部总调整按钮、行尾箭头或完整滑动直接执行。Web 保留第三栏流程。已还期次也可修正，实际流水、余额、已还状态不变。利率表单只提交年利率（含 0%）及生效期次，从选中期起重算后续；金额表单仅填写「本期应还金额」，默认预填该期应还额，仅修改选中一期，前后期次逐项不变。单期修正不修改本金摊销、利息或利率，差额独立显示为「本期金额修正」，汇总按应还额合计，避免把修正伪装为本金或利息。请求使用 kind=payment、scope=period、payment，不再提交持续月供方式；旧服务端应拒绝未知 scope，不能静默修改后续计划。

调息时，生效期之前每一期的日期、本金、利息、应还、剩余本金和利率必须逐项不变。后续以期初剩余本金、新利率和剩余期数重算，保留历史分段月供设置及单期修正的应还金额，支持反复调息；保留原还款日锚点，避免月末漂移。单期金额修正不自动触发提前清偿或改变后续本息。修改回该期计划本息合计时清除修正标记。

先调用服务端只读预览；表单下方以圆角卡片展示选中期起最多三期，每卡显示期次、日期、应还及原应还。本金、利息、年利率排为一行，期次选择中的期数与日期也排为一行。金额预览的后两期完全保留，用于确认范围；不足三期时按实际数量显示。预览成功后才允许保存，输入变化立即清除旧预览。保存依赖计划版本，过期预览须刷新重试。服务端通过白名单 map 原子持久化快照和版本；权限、期次、输入校验及普通 PATCH 历史保护保持有效。

iOS 详情、完整计划、提醒和 Web 使用同一已保存计划。逐期显示实际采用的年利率，自定义月供有简短标记；去掉“固定利率试算”的常驻表述。Web 查看和调整复用第三栏，提交期间锁定关闭。实际余额、交易、已还期数均不因调息自动变化。

测试历史前缀完全不变、两次调息、0% 利率、三种还款方式、自定义月供、尾期补差／提前清偿、31 日跨二月、已还期次及全部已还后的修正、真实流水不变、并发版本、失败回滚、权限隔离、保存后重读、两端编译、真实左滑双按钮、筛选后选期一致和三期卡片预览。

参考工商银行公开合同的重定价与按剩余本金、剩余期限重算约定：[合同原文](https://media.icbc.com.cn/agreement/1259358229168136198.html)。本产品按整期、年利率除以 12 试算，不自动接入 LPR，不模拟期中按日分段计息或费用。
