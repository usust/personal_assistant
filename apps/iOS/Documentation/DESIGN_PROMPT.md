# Personal Assistant iOS · 完整设计与开发提示词

## 角色和交付目标
你是一名熟悉 SwiftUI、iOS 原生交互、个人效率工具和财务数据完整性的资深 iOS 工程师兼产品设计师。请在现有 `apps/iOS/PersonalAssistant` Xcode 工程中实现 Personal Assistant 原生客户端。先核对 Web 的业务流程与后端真实路由，再设计移动端信息架构，完成代码、构建检查、关键逻辑测试和运行说明。不要仅交付设计稿、HTML 页面或不可操作的静态界面。

## 产品定义
这是一个面向个人日常生活的工具：把任务、个人收支和 AI 操作整合为清晰、安静、可信赖的工作空间。主要使用场景是快速查看今天、捕捉任务、随手记账、查询资产以及让助手处理明确的指令。中文优先，默认人民币；以真实 API 为唯一业务事实来源。首页不虚构财务数据，不用示例数据充当生产数据。

## 原生实现边界
使用 SwiftUI、Foundation、URLSession、Security / Keychain、Swift Charts、SF Symbols。禁止 WKWebView、网页嵌套、Web 页面转壳、HTML/CSS 模拟系统控件。Markdown 使用原生 AttributedString 文本渲染。项目不依赖第三方包。

## 信息架构
1. **今日**：日期、问候、当日与逾期未完成任务、快速添加、本月财务摘要、助手入口。首屏信息精简，完整记录由二级页面承载。
2. **任务**：清单筛选、搜索、进行中/归档切换、任务树详情、创建与编辑、日期和时间、优先级、进度配置与增减、归档/恢复、排序和明确确认的级联删除。
3. **财务**：净资产、隐藏金额、本月收支与结余、原生趋势图、支出分类；账户管理、收支/转账、分类管理、流水搜索/筛选/分页、AI 草稿确认与冲销。
4. **助手**：选择可用模型、提问建议、原生对话、输入框随键盘避让、发送中状态、真实操作成功/失败结果、清空对话。对可能执行过的超时请求不能自动重发。
5. **我的**：资料、AI 配置、管理员用户管理、本机外观偏好、当前服务器、退出登录。

iPhone 使用系统底部 TabView；iPad 使用 sidebarAdaptable，宽内容居中控制阅读宽度。详情由 NavigationStack 推进，创建/编辑由 Sheet + Form 展示。主要操作采用标准右上角位置。删除和影响余额的操作使用系统确认界面。

## 视觉与交互
- 系统动态字体；标题层级明确，正文至少采用系统 body，说明采用 subheadline/caption。允许文字换行，不以固定高度截断长内容。
- 背景使用 systemGroupedBackground，内容使用 secondarySystemGroupedBackground，文字使用 primary/secondary。跟随系统深浅模式，也允许本机选择。
- 强调色为系统 teal；橙色辅助表达支出/优先级；红色用于失败/破坏性操作。状态同时提供文字和符号，不仅依赖颜色。
- 卡片圆角约 22–28 pt，基础边距 16–24 pt；行内图标容器约 44 pt。用间距分组，减少装饰边框。
- Liquid Glass 优先来自系统 Tab、Toolbar、Sheet 与玻璃按钮。正文、金融数字和输入表单保持稳定底色，避免叠加玻璃遮挡信息。
- 使用系统交互支持动态字号、VoiceOver、键盘安全区、降低动态效果与降低透明度偏好。进度环提供文字百分比，图表同时提供可读的金额文本。
- 处理首屏加载、空列表、搜索无结果、请求失败、重试、提交中、登录过期；不把未加载状态显示为真实零余额。

## 数据与安全
- baseURL 可配置，默认与仓库后端一致：`http://localhost:16101/api`。公网使用 HTTPS；仅 localhost、IPv4 回环、RFC 1918 私网与 `.local` 调试允许 HTTP，不全局关闭 ATS。
- 图片验证码来自后端 PNG Data URL；失败后刷新挑战。账号密码只在表单内存中使用。登录 token 按服务器隔离存储于设备钥匙串。
- 所有请求使用 Bearer，401 清理当前会话；旧会话响应不得覆盖新会话；拒绝自动重定向传播凭证。
- PATCH 从字段白名单构造字典，比较原值，仅发送实际改变字段；支持 false、0、空字符串；不得以整个模型覆盖未提交字段。
- 财务金额以十进制字符串传输和 Decimal 展示；Double 只可用于图表坐标。新增交易使用 requestId；同一请求重试复用键，不自动重试财务或 AI 写入。
- 任务汇总包括归档子节点，防止循环关系；遵循现有 Web 的空主任务展示规则。删除清单会级联删除任务，确认文案必须真实说明。
- 不调用后端未实现的日历、偏好、信用卡、贷款、房贷接口。若未来恢复，必须先验证路由与契约。
- 不引入远程埋点，不记录 token、密码、AI Key；生产模式不缓存敏感业务数据。仅 Debug 的明确 `--preview` 参数可启用只读示例。

## 账户机构目录与信用账户（2026-09-27 补充）

### 当前选择范围（按用户最新标注精简）
- 选择页按资金、信用、充值、理财、应收、应付六类展示 66 个类型入口，使用圆形图标、名称和右箭头。储蓄卡与信用卡进入银行二级列表，银行仅保留国有大型、全国股份制、网络与民营、城市商业银行。
- 移除农村商业银行、农村合作银行、农村信用社与联合社、村镇银行、农村资金互助社、外资法人银行、外国及港澳台银行内地分行、政策性与开发性银行、住房储蓄银行九类。分类入口、全局搜索及信用卡发卡机构列表统一排除这些类别。
- 当前可选银行为 161 家，首页有 66 个类型入口（含两个银行导航入口）。完整源目录仅用于历史机构兼容与审计，不恢复被移除的选择项；已有账户名称、类型、图标和余额不变。自定义入口继续可用。

### 源数据覆盖范围与来源
- 将账户类型和机构名称合并为一个原生「账户类型」选择入口，每个选项展示图标和名称；新增必须先选择账户，再填写必填账户名称（如「招商银行工资卡 8888」）及选填备注；不单独要求尾号。iOS 采用同页两张圆角卡片：第一张机构／名称／备注，第二张余额／人民币币种／计入净资产；默认 0 元／人民币／计入净资产，历史尾号保留。
- 中国大陆银行目录必须按金融监管总局可核验的完整公开名录导入，覆盖国有大型银行、股份制银行、城商行、民营银行、直销银行、农商行、农村合作银行、农村信用社／联合社、村镇银行、农村资金互助社、政策性／开发性银行、住房储蓄银行、外资法人银行及在内地的外国／港澳台银行分行。不得用十几家常用银行或几个地区的示例冒充完整目录。
- 明确「全部」的口径：覆盖所引用快照中的上述机构类别，不代表实时营业状态，也不将普通营业网点重复列为独立银行。保留来源 URL、名单截止日期、获取日期、机构编码、原始全称、分类、来源文件校验值、导入规则和数量核对。发现新快照时可通过脚本更新并验证，禁止根据名称猜造机构。
- 网络银行作为便于查找的产品分组，不作为新的监管类别；微众、网商、新网、百信等应有可搜索的官方名称和常用别名。目录离线可用，不能依赖运行时远程图标或抓取监管网页。
- 支付钱包、信用卡、花呗、白条等信用账户、现金、储蓄与投资账户独立分组。平台产品与持牌银行明确区分，产品选项不代表授信、开户或该用户具备使用资格。

### 原生选择体验
- 首页采用六个用途分组的圆角列表卡片；银行目录采用二级懒加载列表；支持跨分类搜索中文全称、简称、所在地文字、英文名、拼音和拼音首字母，不要求用户逐行滚动查找。
- 银行信用卡采用「信用卡 → 选择发卡机构」的渐进选择；仅表示用户已有卡的记账分类，不暗示每家银行都发行信用卡。不把每家银行的借记与信用选项重复堆在首页。
- 选中后一次性更新机构及对应账户类型，并返回编辑页；返回、取消、重复选择不会重置草稿或悄悄重写历史机构名称。
- 保留手动添加银行／合作社、钱包、信用或其他账户的入口，供新设、更名及目录未收录机构使用。自定义名称需非空且符合服务端字节长度限制；不修改公共目录。
- 已有品牌图标复用本地有来源的素材；缺失品牌标志时采用清晰的通用机构／信用图标，不伪造商标。长名称换行，正文使用 primary，选中状态用勾选表示，支持动态字体、深色模式和 VoiceOver。

### 数据与信用记账边界
- 先核对真实账户接口允许的 accountType。目录的产品分组与 API 类型分离；只提交服务端支持的字段和值，不因新增展示分组调用不存在的信用卡／贷款 API。
- 当前通用账户账本可用银行类型承载银行卡、其他类型承载平台信用账户；信用卡机构名称携带明确的「（信用卡）」标记，以便重新打开时恢复信用展示。已有字段不自动迁移，旧机构名称原样保留。
- 信用余额使用同一有符号账本：欠款为负，溢缴款为正，授信额度不是资产也不是余额。提供明确输入说明；还款以转账记录，不重复计为支出；本次不实现额度审批、账单日、还款日、分期计息或自动扣款。
- 新增／编辑／重新打开及交易选择均使用同一目录解析；PATCH 只提交实际变化，不把整份目录或新增本地元数据发给后端。

### 必须验证
- 校验官方源总行数、筛选类别计数、机构编码唯一性、无漏行／重复行／跨页截断，生成资源可由导入脚本复现。
- 测试保留的大行、城商行、网络银行、信用卡和平台信用账户可选可搜索；被移除九类不可通过搜索或信用卡入口重新出现，但已有账户仍能解析；覆盖拼音、历史别名、自定义、空机构和旧账户数据保护。
- 验证信用欠款对净资产的符号、转账还款的余额方向与不重复计支出；不通过自动取绝对值掩盖正负错误。
- 完成 Debug／Release 编译和关键回归，记录实际验证范围；未经模拟器／真机或真实 API 验证的项目如实标注。

- 参考用户提供的新增账户页面：系统浅灰背景，26pt 圆角卡片，20pt 页面边距，卡片间隔 16pt；iPad 内容最大宽度 600pt。
