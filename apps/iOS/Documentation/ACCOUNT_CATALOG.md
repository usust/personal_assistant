## 当前界面范围（按用户最新标注精简）

可选银行限定为国有大型银行 6 家、全国股份制银行 12 家、网络与民营银行 20 家、城市商业银行 123 家，共 **161 家**；首页按六类展示 66 个账户类型入口，其中储蓄卡、信用卡进入银行列表；两个银行入口使用同一范围。

已移除农商行、农村合作银行、农村信用社与联合社、村镇银行、农村资金互助社、外资法人银行、外国及港澳台银行内地分行、政策性与开发性银行、住房储蓄银行九类。下述完整源数据用于审计及历史账户解析，不代表当前界面可选范围。已有账户不删除、不改写，手动添加机构仍可用。

## 支付、信用与其他选项

当前产品目录由 `shared/finance/account-kinds.json` 统一维护：资金、信用、充值、理财、应收、应付六类，共 66 个入口，含两个银行导航入口和 64 个具体类型。旧资源的 11 个平台／其他项仅作为兼容数据；完整银行源资源仍为 3,264 项，不代表首页展示数量。银行信用卡在 161 家银行范围内动态构造，不重复存储银行条目，也不声称每家机构都发行信用卡。

产品名称核验来源：[蚂蚁集团](https://www.antgroup.com/)、[京东白条](https://uap.jr.jd.com/baitiao)、[京东金融帮助中心](https://jrhelp.jd.com/show/helpcenter)、[微粒贷官网](https://w.webank.com/)。这里只记录用户已有账户，不开户、不授信、不提供利率或可用资格判断。

- 机构入口统一图标＋名称，另有可选别名；机构正式全称作为新账户的 `institution`。
- 首页展示六类用途卡片；类型搜索和二级银行搜索分别检索产品及银行。银行搜索支持中文、英文、简称、地区文字、全拼、拼音首字母和多词搜索。列表使用原生 `List`，长名称换行，正文使用 `primary`。
- 缺失、新设或更名机构可手动输入，不修改全局目录。长度按 API 的 128 UTF-8 字节（含信用标记）限制。
- 银行信用卡沿用 `accountType=bank`，机构字段带 `（信用卡）`；平台信用账户使用现有 `other` 类型。自定义信用产品带 `（信用账户）`。这些可恢复标记不修改后端契约、不调用停用的信用卡／贷款接口。
- 欠款记为负余额、溢缴款记为正余额；授信额度不计入余额。消费记支出，还款记转账。通用账本已经按余额符号计算负债与净资产。
- PATCH 仍只提交白名单中的实际变化。目录中找到历史别名时只改善图标和显示，不自动覆盖服务器原始名称。

## 生成与更新

生产资源：`PersonalAssistant/Resources/AccountProviders.json`。审计数据：`Documentation/AccountProviders.audit.json`，含完整 3,619＋114 行提取结果、源 PDF SHA-256、分类计数与剔除类别，不打包进 App。品牌名称与别名覆盖项：`Scripts/Data/provider-overrides.json`。

下载上述两个官方 PDF 后执行（Python 环境需有 `pdfplumber`，macOS 需 Xcode Swift）：

```sh
python3 apps/iOS/PersonalAssistant/Scripts/import_bank_catalog.py \
  --banks /tmp/nfra-banks-202512.pdf \
  --branches /tmp/nfra-branches-202512.pdf
```

导入逐行检查六列、连续序号、全量总数、机构编码唯一性和格式、每个监管类别计数。只去掉显示名末尾的公司法律形式，不删地域或分行。拼音由离线 Swift/Foundation 脚本生成，并修正「银行／分行」及长沙、厦门等常见地名的多音字读音，App 运行时不做网络请求。

更新新快照时先核对官方截止日期、总数与分类，更新脚本锁定的日期／计数／URL，再生成并运行测试；不得关闭断言来绕过不匹配。可用 `--output` 和 `--audit-output` 写临时目录，与已提交资源比对以验证可复现性。

## 验证边界

- iOS 核心测试覆盖目录总数、所有机构类别、拼音和多词搜索、网络银行简称、信用卡与平台信用账户恢复、旧账户原值保留、自定义与字节上限、损坏资源拒绝。
- 后端临时 SQLite 回归 `TestCreditAccountLedger` 验证负余额计负债、信用消费、还款转账不重复计支出、净资产不受还款影响。
- Debug／Release 使用模拟器 SDK 构建，资源随 App 打包。
- 本轮未完成模拟器交互截图及真实服务器写入联调；不将编译和内存／临时数据库测试表述为端到端验收。

## 跨端资源同步

修改 `shared/finance/account-kinds.json` 后执行 `node scripts/sync-account-catalog.mjs`，生成 iOS AccountKinds.json 与 Web account-kinds.json、account-banks.json。加 `--check` 可检测两端是否漂移；Web build 已接入此检查。新设计规范见 `docs/design/account-type-selection.md`。
