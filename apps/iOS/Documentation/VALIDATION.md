## 局域网 IP 修复补充（2026-09-26）

用户提供实际监听端口 20000 后，确认原 normalize 校验只接受 localhost / .local / 127.0.0.1，导致 RFC 1918 IPv4 在发起请求之前被拒绝。现已加入严格的四段十进制私网/回环校验，并在 Info.plist 配置对应 CIDR HTTP 例外；公网 HTTP 仍被拒绝。

- `http://192.168.88.185:20000/api/health`：在沙盒外从本机请求得到 HTTP 200，`status=ok`。
- `http://127.0.0.1:20000/api/health`：HTTP 200。
- 回归测试扩展为 47 项且全部通过，包含用户地址、私网边界及伪装主机名。
- Debug iOS Simulator arm64 构建通过，已检查产物 Info.plist 包含四段 CIDR 例外。
- 需在手机重新编译运行新版，并允许「本地网络」权限；本机健康检查不等同于手机到 Mac 的链路验证或真实账号联调。
- ATS 配置依据：[Apple NSExceptionDomains](https://developer.apple.com/documentation/bundleresources/information-property-list/nsapptransportsecurity/nsexceptiondomains)，公开 API 支持 IPv4/IPv6 地址与 CIDR 范围。
